# 🛡️ Cybersecurity Project – Active Directory Attack & Defense

## 📌 Project Overview

This project demonstrates the configuration, attack simulation, investigation, and defense of an Active Directory environment. The project uses a virtualized Windows domain environment to explore common Active Directory attack techniques and the security controls used to detect, mitigate, and prevent them.

The project focuses on gaining practical experience with Active Directory security by expanding an existing domain environment, simulating controlled attacks, analyzing their impact, implementing defensive measures, and verifying that those measures are effective.

---

## 🖥️ Environment

- Windows Server 2022
- Windows 11
- Active Directory Domain Services (AD DS)
- Oracle VirtualBox
- Windows Event Viewer
- PowerShell
- Additional security tools introduced throughout the project

---

## 🎯 Project Objectives

- Expand and configure a realistic Active Directory environment.
- Understand common Active Directory attack techniques.
- Simulate attacks in a controlled environment.
- Analyze Windows and Active Directory evidence generated by attacks.
- Implement defensive controls and security hardening.
- Verify the effectiveness of implemented defenses.
- Develop practical Active Directory attack and defense experience.
